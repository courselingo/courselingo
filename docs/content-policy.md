# 内容策略 · Content Policy

> **必读。** 这份文档的作用是让项目不侵权。授权风险是本项目最大的敌人，比翻译质量更能决定生死。

## 核心原则

**我们发布的是自己写的讲解，不是别人课程的复制品。**

这一条不是道德姿态，而是法律结论：

- **思想与概念不受著作权保护**，表达才受保护。
- 因此「我们自己写一篇讲解同样概念的原创文章」风险最低。
- 而「翻译完整逐字稿」或「翻译视频字幕」属于**衍生作品**，它复制了原作的全部表达 —— 风险完全取决于原课程的实际许可条款。

这直接决定了产品的默认形态：**讲解为主，翻译为辅**。

## 内容分级

> 下表是**一般著作权推理**（ideas vs. expression），**不是**已核实的许可条款。最终以各课程实际条款为准。

| 做法 | 风险 | 说明 |
| --- | --- | --- |
| 自己撰写讲解，讲同一批概念 | 🟢 最低 | 概念不受保护。但须避免逐句改写原文、避免复制原图 |
| 链接官方来源 + 自己的解读与署名 | 🟢 低 | 署名是伦理规范，**但它本身不能豁免侵权** |
| 翻译完整讲座逐字稿 | 🟡 高 | 衍生作品，复制全部表达；须有明确许可 |
| 翻译视频字幕 | 🟡 高 | 同上，且叠加视频平台条款 |
| 转载原始课件 / 视频 | 🔴 最高 | 即使许可宽松，视频还另有平台条款；**一律链接，不转载** |
| 翻译官方作业答案 | 🔴 最高 | 著作权 + 学术诚信双重风险；且答案常被故意不公开 —— 默认无授权 |

## 署名与标注规范

任何涉及具体课程的产出，文件头部**必须**包含：

```markdown
> 来源课程：MIT 6.5840 / 6.824 Distributed Systems
> 对应内容：Lecture 3 — Primary-Backup Replication
> 官方链接：https://pdos.csail.mit.edu/6.824/
> 授权依据：<已核实条款 / 待核实 —— 未核实不得发布>
> 本文为 CourseLingo 原创讲解，非官方材料，与原课程方无隶属关系。
```

页面与仓库层面还须显著标注：

- 「非官方 · 社区项目」
- 不得使用任何学校校徽、课程 Logo
- 不得暗示官方背书或合作关系

## 下线机制

任何仓库中的内容，一旦被指出超出授权范围：

1. **立即下线**（不回退讨论、不等核实结论）。
2. 在对应仓库开 issue 记录决策。
3. 复盘该课程的授权判断是否有系统性偏差。

宁可错杀，不可拖延。

## 逐课程复核清单

每门课程在开工前，必须书面确认以下各项：

- [ ] 讲座笔记 / 幻灯片 的许可条款
- [ ] 讲座视频 的许可条款（注意与课件可能不同）
- [ ] 作业 / Lab 题面与答案 的许可条款
- [ ] 教材（如有）的许可条款
- [ ] 课程页是否有明确的 reuse / citation 声明
- [ ] 是否允许**商业**使用
- [ ] 是否允许**衍生作品**（翻译即为衍生作品）
- [ ] 是否有 **ShareAlike**（相同方式共享）要求，是否会传染到我们的产出
- [ ] 署名要求的具体形式

## 兜底原则

**条款未核实 = 不发布。**

若某课程确实需要翻译逐字稿或字幕，正确路径是**先写信取得授权** —— 联系课程讲师或相应版权办公室，而不是先发布再说。
