# 产出形态的决定 · 「翻译」还是「讲解」

> 记录人：CourseLingo Lead ｜ 日期：2026-09-29
> 起因：用户目标「继续，至少全量翻译完 4 门课程。」
> 本文回答一件四个作者都会问到的事：**每讲到底产出什么？**

## 1. 先把两个词在本项目里的含义钉死

| 词 | 对应字段 | 本项目定义（逐字引自 `content-policy.md`） |
| --- | --- | --- |
| **讲解** | `output_mode = "explanation"` | 「我们自己写的讲解，不是别人课程的复制品」；「自己写一篇讲解同样概念的原创文章，风险最低」 |
| **翻译** | `output_mode = "transcript"` | 「**翻译完整逐字稿**」；「属于**衍生作品**，它复制了**原作的全部表达** —— 风险完全取决于原课程的实际许可条款」 |

**⇒ 所以在本项目里，「翻译」是一个**法律含义很重**的词：它指的是**复制原作全部表达**的衍生作品。**
**⇒ 而 `content-policy.md` 明写：「产品的默认形态：**讲解为主，翻译为辅**。」**

## 2. 用户这次说的是「翻译」，而约束是别的

用户目标逐字：**「继续，至少全量翻译完 4 门课程。」**

**而同时成立的还有用户此前给的内容方针（逐字）**：
> 「重点是要**易懂易学**……让**基础不好的初学者**也较能接受。**需要减少 AI 味的表达**。」

**⇒ 这两条有张力**：
- **逐字译**（transcript）会**保留原讲义的表达与节奏** —— 而讲义是给课堂上的人看的，**不是给基础不好的自学者看的**；
- 「易懂易学 + 初学者 + 少 AI 味」要求的是**重述**，而不是**搬运**。

## 3. 决定

**⇒ 每讲产出 = 「紧贴原文结构的中文讲解」，`output_mode = "explanation"`。**

具体形态（四个作者照此办理）：

| 要素 | 要求 |
| --- | --- |
| **结构** | **跟随源讲次的推进顺序**（哪一节先讲什么，就按那个顺序）—— 这一点让产出**可对照原文**，也就承担了「翻译」的可验证性 |
| **术语** | 每个术语**首次出现给中英对照**，之后用中文；术语取自 `glossary.toml` |
| **难句/关键定义** | **给出原文短引 + 中文**（一两句，不是整段）—— 精度要求高的地方必须能回到原文 |
| **其余** | **用易懂中文重述**，讲清「为什么」与「不这样会怎样」 |
| **不做的** | **不产出逐字全译**；**不做双语并排全文**（那走同一道闸门，见 `content-policy.md` 第 110 行） |
| **配图** | **自绘 SVG，不转载原图**（房规硬要求） |

## 4. 为什么这样定（四条理由，可复核）

1. **用户的风格方针**是硬约束，而逐字译与它冲突（见 §2）；
2. **项目自己的政策**是「讲解为主，翻译为辅」（`content-policy.md` L15）；
3. **规模**：四门全量约 **100 讲**（31 + 21 + ~24 + ~25）。**逐字译 + 讲解两遍 = 200 讲的工作量**，
   在本目标的轮次预算内不可行 —— **必须二选一**；
4. **法律边际**：讲解是「不复制对方表达」的最低风险形态；逐字译把风险完全绑在上游许可上。
   **上游许可已双签**（见 `full-translation-scope.md` §3），**所以逐字译是被允许的 —— 但它不是必需的**。

## 5. 而**授权允许逐字译**这件事，仍然要如实记录

**⇒ 四门课的 `transcript` 现在都是**解锁**状态**（第二人复核已签字）。
**⇒ 本文只是**选择了不做**，不是**不能做**。**

**⇒ 若用户明确要逐字译**（例如「我要能对着英文原文读」），**改 `output_mode` 即可，无需重新核实授权** ——
**唯一还要补的是：该讲**实际依据的那份材料**单独取证一次**（逐页原则，见 §6）。

## 6. 无论选哪种形态，两条义务都不变

1. **逐页取证**：把某讲改为 `transcript` 之前，**该讲依据的那份材料页要单独抓一次** ——
   OCW 的许可是逐页复制的，ETH 是逐页页脚，CS168 是教材根页 + 具体章节页；
2. **两道人工闸门 + 五道机检**：非作者事实核对、配图视觉复核，加 `validate` / `check_style` /
   `audit_content --strict` / `check_figures --strict` / `build_site`，以及提级前的 `check_reviewed`。

## 7. 一句话给四个作者

> **按源讲次的结构写中文讲解，术语给中英对照，难句给原文短引；
> 不逐字全译，不转载原图。**
