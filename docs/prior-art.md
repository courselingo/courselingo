| 项目 | 形态 | 覆盖 | 许可 |

| [yeasy/llm_internals](https://yeasy.gitbook.io/llm_internals) | GitBook | 大模型原理（非 6.824，作**体例**参考） | 未核实 |

**结论一：这不是一片空地。** 6.824 已有流行中文版，所以我们不能靠「首个中文版」立足。
差异点必须落在**对照方式、授权合规、配图、可机检**上。

### 1.1 他们的授权状态（重要）

huihongxiao 的 README 声明原文：

> 此次翻译纯属个人爱好，**如果涉及到任何版权行为，请联系我，我将删除内容**。

GitBook 侧的 `llms.txt` 里 `版权 / 许可 / license / CC / ©` 出现 **0 次**。

也就是说：**那不是一份许可，而是一份「可能侵权、欢迎来函即删」的免责声明。**
他们翻译的是**视频讲课内容**（README 自述「这门课程是全英文，甚至英文字幕都没有」），
而视频的权利状态正是我们核实过的**未确认**项（见 [paper-licensing.md](./paper-licensing.md) §6）。

**对我们的意义有两条：**
1. **不能从他们那里拷贝任何文本** —— 无许可 = 保留全部权利。
2. 反过来说，我们坚持「授权未确认就不做全文翻译」的闸门是对的：
   同样的路，我们已经用 `redistribution = "unknown"` 判为不可发布。

## 2. 我们采纳的（他们做得对的）

### 2.1 `llms.txt` + 每页 Markdown ✅ 已实现

两个 GitBook 都提供：
- `/llms.txt` —— 全部页面的 Markdown 索引
- 每页 `.html` 旁边再放一份 `.md`（把 `.html` 换成 `.md` 即可）

对 Agent 抓文档极友好。我们的内容本来就是 Markdown，成本几乎为零，
已在 `scripts/llms.py` 实现（构建时发布，并把 `:::bilingual` 指令**展开成
中英交替的可读文本** —— 否则 LLM 只会看到一条无法解析的路径指令）。

### 2.2 章节级细粒度（**待决**）

他们的体例是**一课拆 6–9 页**（`1.1`、`1.2`…`3.8`、`6.1`…），我们目前是**一课一页**。

| | 一课一页（我们） | 一课多页（他们） |
| --- | --- | --- |
| 单页长度 | 3.5k–5.8k 汉字，偏长 | 每页短，好读 |
| 导航 | 侧栏只有 3 项 | 侧栏展开到知识点 |
| 链接 | 一节一个锚点 | 一节一个 URL，可单独分享 |
| 成本 | 已写完 | 要重新切分内容 |

**这是待你决定的一项**，不是技术限制。

## 3. 我们刻意不做的

| 无许可发布 | 授权闸门（不通过就**拒绝构建**，退出码 3） | 见 [content-policy.md](./content-policy.md) |
