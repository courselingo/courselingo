# 品牌规范 · Brand

## 命名

| 项 | 值 |
| --- | --- |
| 组织 / 标识 | `courselingo` |
| 显示名 | CourseLingo |
| 中文主名 | **译课 AI** |
| 中文备用名 | 课语 AI（副品牌，非优先，仅在不便使用主名时） |
| 英文口号 | AI-powered translation & explanation for classic CS courses. |
| 中文口号 | **让经典 CS 课程，跨语言也能学懂。** |

命名理由：`CourseLingo` = Course + Lingo，兼顾「课程」与「语言」。中文主名 **译课** 直指功能（译 + 课），搜索与传播都比抽象品牌名更直观。

## 语气（Voice）

- **像助教，不像营销号。** 直接讲清楚，不铺垫、不煽情。
- **承认复杂。** 遇到难概念不粉饰成「其实很简单」，而是拆开讲。
- **不吹牛。** 进度、局限、授权边界都如实写。Phase 0 就写 Phase 0。
- **中英并用有纪律。** 术语首次出现给「中文（English）」，之后统一用中文。

## 用词规范

- 用「讲解」而非「解析」（后者偏试题语境）。
- 用「课程」而非「网课」。
- 避免「全网最全」「颠覆」「封神」这类词。
- 面向读者写「你」，不用「用户」「学员」自称读者。

## 视觉（建议稿，未定稿）

Phase 0 不急于定视觉。若需要一版可直接用的，建议以「书 + 语言」为意象，避免用大学校徽或课程 Logo（**涉及商标，禁止使用**）。

## Logo 资源

放在仓库 `assets/` 下，随 `template/assets/` 一起复制进每个课程仓库。

| 文件 | 用途 | 说明 |
| --- | --- | --- |
| `logo.png` | **浅色底**上的展示（README、文档、幻灯片） | 512×511，透明通道，已按 alpha 阈值裁掉晕影 |
| `logo-avatar.png` | **GitHub 组织头像**、深色底 | 512×512，浅色实底，内容缩到画布 70% —— **圆形容器裁切安全** |
| `logo-square.png` | 需要正方形实底时 | 512×512，浅色实底，内容占 87% |
| `favicon.png` / `favicon-32.png` | 站点图标 | 由头像缩放，`build.py` 会自动引用 |

### ★ 为什么必须有「浅色底」版本

实测对比度（WCAG 相对亮度）：

| 元素 | 在白色上 | 在深色上 |
| --- | --- | --- |
| 主蓝 `#0040c0` | **8.4:1** ✅ | **2.2:1** ❌ |
| 浅灰 `#e0e0e0` | 1.3:1 ❌ | 14.3:1 ✅ |

**这个 logo 是为浅色背景设计的。** 蓝色元素在深色底上只有 2.2:1，基本看不清。
所以：

- README / 组织主页用 `<picture>` 按主题切换：浅色用透明版，深色用浅底版。
- 站点页头把透明 logo 放在一张**白色小底片**上（`.brand-logo`），明暗主题下都清晰。

### 头像必须是「圆形容器安全」的

GitHub 组织头像会被裁成**圆形**。原始图内容占画布 87%，四角会被圆切掉，
所以 `logo-avatar.png` 把内容缩到 70% 并居中 —— 这样才不会被裁。
