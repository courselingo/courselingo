# 品牌规范 · Brand

## 命名

| 项 | 值 |
| --- | --- |
| 组织 / 标识 | `courselingo` |
| 显示名 | CourseLingo |
| 中文主名 | **译课 AI** |
| 中文备用名 | 课语 AI（副品牌，非优先，仅在不便使用主名时） |
| 英文口号 | AI-powered translation & explanation for classic CS courses. |
| 中文口号 | **让经典 CS 课程，跨语言也能学懂。** |

命名理由：`CourseLingo` = Course + Lingo，兼顾「课程」与「语言」。中文主名 **译课** 直指功能（译 + 课），搜索与传播都比抽象品牌名更直观。

## 语气（Voice）

- **像助教，不像营销号。** 直接讲清楚，不铺垫、不煽情。
- **承认复杂。** 遇到难概念不粉饰成「其实很简单」，而是拆开讲。
- **不吹牛。** 进度、局限、授权边界都如实写。Phase 0 就写 Phase 0。
- **中英并用有纪律。** 术语首次出现给「中文（English）」，之后统一用中文。

## 用词规范

- 用「讲解」而非「解析」（后者偏试题语境）。
- 用「课程」而非「网课」。
- 避免「全网最全」「颠覆」「封神」这类词。
- 面向读者写「你」，不用「用户」「学员」自称读者。

## 视觉（建议稿，未定稿）

Phase 0 不急于定视觉。若需要一版可直接用的，建议以「书 + 语言」为意象，避免用大学校徽或课程 Logo（**涉及商标，禁止使用**）。

| 用途 | 建议值 |
| --- | --- |
| 主色 | `#2563EB`（可信赖的蓝） |
| 强调色 | `#F59E0B`（标记「讲解」部分） |
| 正文色 | `#1F2937` |
| 中文字体 | 思源黑体 / 系统默认无衬线 |
| 英文字体 | Inter |

## 禁止事项

- 不得使用 MIT、UC Berkeley、CMU、Stanford 等学校的**校徽、校名 Logo**，或暗示官方背书。
- 不得让页面看起来像课程**官方**站点，必须显著标注「非官方 · 社区项目」。
- 不得在未经授权时使用课程名称作为产品名（描述性引用是允许的，见内容策略）。
