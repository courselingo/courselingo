# 判据体系索引（本会话长出来的部分）

> 本文件只是**索引**，正文在 `quality-audit.md`（2267 行）。建立它是因为本会话新增了十三条，
> 而它们分属三种**不同用途** —— 混在一起读会看不出差别。

## 【发现类】怎么**看到**一个错

| 附录 | 一句话 |
| --- | --- |
| 十四 | 结论的适用范围 > 它引用的证据范围 |
| 十五 | 本地的改动，非本地的后果（改了 A，没改引用 A 的 B） |
| 十六 | 一个元素的作用范围 > 它的显性用途（删它之前先问它还在替谁承重） |
| 十七 | 字面不可靠时按**结构**定位（且必须断言命中数） |
| 十八 | 限定词会换掉论域 |
| 二十 | 方向错误：两个方向都读得通的那一类 |
| 二十一 | 两处「看不见」：异写的数字（`~4K` vs `4000`、`C P U` vs `CPU`），与不渲染的字段（`desc`） |
| 二十四 | 源材料没说时不要**填补**它 —— 「回源」这个动作在这里查不到任何东西 |
| 附录十 补记 | 图内自相矛盾：四类语义载体（可见文字 / `desc` / 箭头方向 / 位置与形状） |

## 【更正类】改的时候**别改错方向**

| 附录 | 一句话 |
| --- | --- |
| 十九 | 改了结论 ≠ 重新取了证（换归因对象不是重新取证） |
| 二十二 | 矛盾该被解释，不该被抹掉（改顺的代价是篡改证据） |

## 【消除类】怎么**让它不发生**

| 附录 | 一句话 | 它依赖什么 |
| --- | --- | --- |
| 二十三 | 一页里有两组互相约束的证据时，别只找你想要的那个数（**扩大取证面**，但它不能替代「我核不到」） | 依赖核对者想到去看同页的第二组证据 |
| 二十五 | 两道**看不同东西**的闸门独立指向同一处时，那处是**真的缺** | 依赖同时跑两道闸门 |
| **二十六** | **让一类错误画不出来，而不是画完再查** | **不依赖任何人记得查** |

**★ 二十六 是这一组里唯一一条**不依赖执行者记性**的，而它带数据**：
`mlsys-author` 已交的第 6–10 讲共 **70 张图，`marker-end` 命中数为 0**，
而**这五讲没有任何方向/顺序类错误**；本会话抓到的三条方向错误全部落在**图上有箭头的第 1–3 讲**。
**⇒ 它的话：「箭头一旦画上，就多了一个会说反话的东西。」**
